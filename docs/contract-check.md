## Surprises

1. **The default model failed; an explicit model works.** Sessions created without a `model` use the user's default model, which in the first run (`fledge-alpha-free`) failed with a malformed tool call, so tsk will inherit whatever model OpenCode defaults to. The rerun created the session with `model: {providerID: "anthropic", id: "claude-haiku-4-5"}` and the question/form chain worked.
1a. **Cancelling a form interrupts the execution.** The cancel produced `session.execution.interrupted` (`reason: "shutdown"`), not `session.idle` or `session.execution.succeeded`. tsk must treat `session.execution.interrupted` as the end of a cancelled run, and read the session from `data.sessionID` on `form.cancelled` (`form.created` uses `data.form.sessionID`). Whether `session.idle` / `session.execution.succeeded` fire on a normally completed run was not exercised.
2. **`herdr pane run` command form.** Pass the command as a single string; unquoted arguments starting with `-` are parsed by herdr, and `--` is typed into the shell.
3. **`herdr pane run` prints nothing on success.** Exit 0 and empty output, and the pane needs several seconds before `agent list` reports it. `agent focus` before then returns `agent_not_found` (exit 1).
4. **Unclaim yields `assignee: null`**, not `""`.
5. **`bd init` uses embedded Dolt** in this version (database `tskc` inside the project's `.beads`), not the shared server at 127.0.0.1:3308. Nothing was added to the shared server.
6. **A single `Killed by SIGSEGV`** came from `opencode api GET /api/session/active`; the retry worked.
7. **`/tmp/tsk-contract` was not removed.** The cleanup `rm -rf` was blocked by the CC Safety Net hook because the directory contains `.git`. Left in place for the controller or user to remove.
